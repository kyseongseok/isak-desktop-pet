# 공개 순위표 설정 (구글 시트 + 앱스 스크립트)

휴대폰 웹앱의 🏆 순위표를 켜는 방법이에요. 한 번만 하면 돼요. 구글 계정이 필요해요.

- 서버 코드: [web/rank-server.gs](../web/rank-server.gs)
- 웹앱 쪽: [web/rank.js](../web/rank.js) — 맨 위 `RANK_URL`에 주소를 넣으면 순위표 버튼이 나타남 (비어 있으면 숨김)
- **펫 앱·맥용 앱에는 들어가지 않아요.** 회사는 망분리라 웹앱(휴대폰)에만 있어요

## 1. 시트 만들고 스크립트 붙이기

1. [sheets.new](https://sheets.new)로 새 구글 시트를 만들고 이름을 `이삭이 순위표`로
2. 메뉴 **확장 프로그램 → Apps Script**
3. 왼쪽 `Code.gs` 내용을 모두 지우고 `web/rank-server.gs` 내용을 통째로 붙여 넣기 → 저장(💾)

## 2. 웹 앱으로 배포

1. 오른쪽 위 **배포 → 새 배포**
2. 톱니바퀴(유형 선택) → **웹 앱**
3. 설정
   - 설명: `순위표`
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자** (로그인 없이 휴대폰에서 보내야 해서)
4. **배포** → 권한 확인 화면이 나오면 본인 계정 선택 → "고급 → (안전하지 않음)으로 이동" → 허용
   - 본인이 만든 스크립트라 뜨는 경고예요. 이 스크립트는 **이 시트 하나만** 읽고 써요
5. 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사

## 3. 웹앱에 주소 넣고 올리기

`web/rank.js`의 `const RANK_URL = '';`에 복사한 주소를 넣고, `sh tools/deploy-web.sh`로 다시 올리면 끝.

## 운영

- 시트 `기록` 탭에 한 줄씩 쌓여요: 시간 · 게임 · 이름 · 점수 · 기기 · 기록 · 확인
- **이상한 기록**: 그 줄을 지우면 순위표에서 사라져요 (20초 안에 반영)
- **'확인 필요'**: 점수와 플레이 기록(시간·거리·수확 수)이 잘 안 맞으면 스크립트가 적어 두고 순위표에서 숨겨요. 괜찮은 기록이면 그 칸을 지우면 나타나요
- 받지 않는 것: 나올 수 없는 점수, 이름 없는 기록, 같은 휴대폰에서 15초 안에 또 보내기, 같은 점수 두 번
- 검사 기준(`HARD`, `SOFT`)은 스크립트 맨 위에 있어요. 바꾼 뒤엔 **배포 → 배포 관리 → 수정(연필) → 버전: 새 버전 → 배포** (주소는 그대로)
- 점수 조작을 완전히 막을 수는 없어요 (휴대폰이 계산해서 보내는 구조). 가족·지인용이라 가벼운 검사만 했어요
- 이름은 누구나 볼 수 있어요 → 별명을 쓰도록 결과 화면에 안내가 있어요
- 무료 한도: 앱스 스크립트는 하루 수만 번 요청까지 무료라 가족·지인 규모면 충분해요
