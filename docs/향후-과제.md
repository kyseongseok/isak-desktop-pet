## 검토 메모: 개인 루틴 알림 (2026-10-21)

- 입력 UI가 핵심 제약: 펫 창은 키보드를 못 받음 → 게임처럼 **별도 작은 창**(제목·시각·반복·미리알림)을 띄워 입력. 트레이 "루틴 관리…"에서 열기.
- 저장: `state.routines[]` = { id, title, time:"17:00", repeat:"once|daily|weekdays", lead:0|5, lastFired:"YYYY-MM-DD" }. 당일 1회는 울린 뒤 자동 삭제.
- 표시: 질문과 같은 등급(한 번 위로 올림, 짧은 알림음·깜빡임 없음). 버튼 [확인] [10분 뒤]. 근무확인 알람과는 소리·색으로 구분.
- 우선순위: 근무확인 알람 단계 중엔 루틴을 미룸(알람 끝나면 표시). 집중 중엔 조용히(말풍선만). 말풍선이 바쁘면 1분 간격으로 재시도.
- 1차 범위: 고정 시각 알림만. 간격 반복("2시간마다"), 달력 연동, 요일 지정은 제외.
- 예상 규모: main 40줄(창·IPC·저장) + 렌더러 120줄(체크·말풍선) + 입력 창 HTML 100줄. 상태 머신은 안 건드림.

## 검토 메모: 농업 상식·통계 말하기 (2026-10-22)

- 방식: 새 알림을 늘리지 않고 **기존 케어 메시지 자리(25분에 최대 1번, 4.5초)를 나눠 씀**. 집중·알람·전체화면 억제 규칙도 그대로.
- 설정(트레이·우클릭 "이삭이 이야기"): 일반(케어만) / 가끔(4번 중 1번 농업) / 이삭이 박사(4번 중 3번). 첫 실행 튜토리얼에서 한 번 물어봄. 기본값은 "가끔" 또는 "일반" 중 결정 필요.
- 내용 두 종류를 구분:
  - 상식·원리(시간이 지나도 맞음): 작물 생육 조건, 폭염 때 가축 관리, 제철 농산물 → 부담 없음
  - 통계(착유량, 가격 등): 해가 바뀌면 틀림. 서버 통신 금지라 실시간 갱신 불가 → **"2025년 기준" 연도+출처를 문장에 넣고**, 담당 부서 검수 후 버전마다 갱신. 일 단위로 변하는 가격은 넣지 않거나 연평균으로만.
- 저장: 타자게임 단어장처럼 텍스트 파일 `app/content/agri-facts.txt` (분류 | 문장 | 출처 | 기준연도 | 표시 월). 동료가 직접 문구 추가 가능.
- 월 태그로 제철 연동: 7~8월 복숭아·폭염 대비, 11월 김장 등. 겨울 시즌 모드와 어울림.
- 표정: 기존 연구·농사·농산물 포즈를 박사 모드 대사에 사용.
- 문장 길이: 말풍선 폭 때문에 40자 안팎. 길면 두 줄까지.
- 예상 규모: 렌더러 60줄 + 설정 메뉴 20줄 + 텍스트 파일. 가벼움. 콘텐츠 작성·검수가 실제 작업량의 대부분.
