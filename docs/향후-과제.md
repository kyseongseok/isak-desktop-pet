## 검토 메모: 개인 루틴 알림 (2026-10-21)

- 입력 UI가 핵심 제약: 펫 창은 키보드를 못 받음 → 게임처럼 **별도 작은 창**(제목·시각·반복·미리알림)을 띄워 입력. 트레이 "루틴 관리…"에서 열기.
- 저장: `state.routines[]` = { id, title, time:"17:00", repeat:"once|daily|weekdays", lead:0|5, lastFired:"YYYY-MM-DD" }. 당일 1회는 울린 뒤 자동 삭제.
- 표시: 질문과 같은 등급(한 번 위로 올림, 짧은 알림음·깜빡임 없음). 버튼 [확인] [10분 뒤]. 근무확인 알람과는 소리·색으로 구분.
- 우선순위: 근무확인 알람 단계 중엔 루틴을 미룸(알람 끝나면 표시). 집중 중엔 조용히(말풍선만). 말풍선이 바쁘면 1분 간격으로 재시도.
- 1차 범위: 고정 시각 알림만. 간격 반복("2시간마다"), 달력 연동, 요일 지정은 제외.
- 예상 규모: main 40줄(창·IPC·저장) + 렌더러 120줄(체크·말풍선) + 입력 창 HTML 100줄. 상태 머신은 안 건드림.

## 검토 메모: 농업 상식·통계 말하기 (2026-10-22)

- 방식: 새 알림을 늘리지 않고 **기존 케어 메시지 자리(25분에 최대 1번, 4.5초)를 나눠 씀**. 집중·알람·전체화면 억제 규칙도 그대로.
- 설정(트레이·우클릭 "이삭이 이야기"): 일반(케어만) / 가끔(4번 중 1번 농업) / 이삭이 박사(4번 중 3번). 첫 실행 튜토리얼에서 한 번 물어봄. 기본값은 "가끔" 또는 "일반" 중 결정 필요.
- 내용 두 종류를 구분:
  - 상식·원리(시간이 지나도 맞음): 작물 생육 조건, 폭염 때 가축 관리, 제철 농산물 → 부담 없음
  - 통계(착유량, 가격 등): 해가 바뀌면 틀림. 서버 통신 금지라 실시간 갱신 불가 → **"2025년 기준" 연도+출처를 문장에 넣고**, 담당 부서 검수 후 버전마다 갱신. 일 단위로 변하는 가격은 넣지 않거나 연평균으로만.
- 저장: 타자게임 단어장처럼 텍스트 파일 `app/content/agri-facts.txt` (분류 | 문장 | 출처 | 기준연도 | 표시 월). 동료가 직접 문구 추가 가능.
- 월 태그로 제철 연동: 7~8월 복숭아·폭염 대비, 11월 김장 등. 겨울 시즌 모드와 어울림.
- 표정: 기존 연구·농사·농산물 포즈를 박사 모드 대사에 사용.
- 문장 길이: 말풍선 폭 때문에 40자 안팎. 길면 두 줄까지.
- 예상 규모: 렌더러 60줄 + 설정 메뉴 20줄 + 텍스트 파일. 가벼움. 콘텐츠 작성·검수가 실제 작업량의 대부분.

## 검토 메모: RDA Anything 연동 (2026-10-22)

Anything 소스: `~/claude/rda_anything/RDA_Anything_v2.1/RDA_Anything/app.py` (Python + pywebview, PyInstaller 단일 exe, 설치 없이 아무 위치에서 실행)
- 호출: Electron `spawn`/`shell.openPath`로 exe 실행. exe 위치가 고정이 아니므로 처음 한 번 파일 선택 창으로 고르고 경로 저장. 바탕화면·다운로드는 자동 탐색.
- 색인 재사용: 색인은 exe 옆이 아니라 `%USERPROFILE%\.rda_anything\`(index_<폴더키>.db, roots.json, state.json)에 저장 → 어느 사본으로 실행해도 같은 색인. **추가 색인 불필요.**
- 주의: `SCHEMA_VERSION`(현재 2)이 다르면 옛 DB를 지우고 재생성 → 묶음 사본과 개별 사본의 버전을 맞춰야 재색인 반복이 없음.
- Anything은 단일 실행 잠금이 없음 → 이미 열려 있으면 창이 하나 더 뜸. 연동 시 Anything 쪽에 단일 실행 + "이미 열려 있으면 앞으로" 추가 권장.
- 묶음 배포: electron-builder `extraResources`로 `resources/anything/RDA Anything.exe` 포함, 우선순위는 사용자 지정 경로 > 묶음 사본. 설치 파일 용량 증가(수십 MB). 이삭이 Actions에서 Anything도 같이 빌드하려면 Anything 소스를 깃허브에 올려야 함.
- 라이선스: PyMuPDF가 AGPL → Anything exe를 공개 배포하면 Anything 소스 공개 의무 가능성. 이삭이는 별도 프로세스 실행이라 영향 없음. 묶음 배포 전 확인.
- **망분리**: 내부망에서 깃허브 접속 불가 → "Releases에서 받으세요" 안내는 불가. Anything이 없으면 "연구제도팀에 요청하세요" 같은 내부 안내 문구로. (이삭이 Release도 외부망 PC에서 받아 망연계로 넘기는 용도)
- **Anything이 가끔 멈춤**(강제 종료 후 재실행하면 정상) → 이삭이 이미지 손상 우려. 대응:
  - 기술적으로는 별도 프로세스로 띄우고 손을 떼므로 이삭이는 같이 멈추지 않음
  - "파일 검색" 메뉴는 Anything 위치를 지정한 사용자에게만 표시 (Anything을 이미 아는 사람만 봄)
  - 묶음 배포는 하지 않음 (같이 설치되면 한 프로그램으로 인식됨)
  - 실행 시 "처음엔 조금 걸릴 수 있어요" 말풍선으로 기대치 조정
  - 선택: "Anything 다시 시작" 메뉴(taskkill 후 재실행). SQLite라 강제 종료에도 색인 안전
  - **선행 과제**: Anything 멈춤 원인 조사 (네트워크 드라이브 재연결 대기, onefile 압축 해제, WebView2 초기화 후보 / 멈춤 때의 `.rda_anything/app.log` 확보)
- 1차 권장(수정): Anything 멈춤 해결 후, 위치 지정한 사용자에게만 호출 메뉴. 이후 Anything에 `--folder` 실행 옵션을 추가하면 "최근 폴더 검색" 같은 바로가기 가능. 검색어 입력은 이삭이 창이 키보드를 못 받아 불가.
