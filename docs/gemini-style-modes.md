# 이삭이 스타일 모드 이미지 제작 가이드 (Gemini용)

동료 요청: "점토 인형처럼", "뜨개(패브릭) 인형처럼" 해 달라.

| 모드 | 폴더(예정) | 상태 |
|---|---|---|
| 기본 (무광 클레이 피규어) | `app/renderer/img/` | 완료 |
| 점토 인형 | — | **접음** (2026-10-21). 기본 3D가 이미 무광 클레이 질감이라 두 번 시도해도 차이가 거의 없었음. 아래 기록만 남김 |
| 뜨개 인형 = **겨울 시즌 모드** | `app/renderer/img/winter/` | 다음 작업. 12~2월에 자동 전환 + 트레이에서 수동 선택 |

작업 순서는 [gemini-image-prompts.md](gemini-image-prompts.md)와 같습니다.
**마스터 1장을 먼저 확정**하고, 동작별 이미지는 매번 [마스터] + [2D 원본] 2장을 첨부해 만듭니다.
펫에 들어가려면 포즈 세트가 기본 모드와 **파일 이름이 같아야** 합니다(idle, blink, runA/runB, alarm, fly, surprise, think, best, hello, cheer, curious, research, farm, angry, sleep…).

---

## 뜨개 인형 = 겨울 시즌 모드

질감 차이가 확실해서(뜨개 코 무늬) 작은 크기에서도 기본 모드와 구분됩니다.
겨울 느낌을 더하려고 캐릭터 디자인을 바꾸진 않습니다. 재질만 털실로 바꾸고, 원래 있는 빨간 스카프를 **목도리처럼 조금 두툼하게** 뜨는 정도만.

### 1단계: 마스터 프롬프트

첨부: `기본 모드 마스터(idle.png)` + `00_기본.png`

```
첫 번째 이미지는 우리 기관 캐릭터 "이삭이"의 3D 버전이고, 두 번째 이미지는 2D 원본 디자인(기본 포즈)이야.
이삭이를 "털실로 코바늘 뜨기한 아미구루미 인형"으로 다시 만들어줘.
생김새·색·비율·포즈는 첫 번째 이미지를 그대로 따르고, 재질만 손뜨개 인형으로 바꿔줘.
실제 손뜨개 인형을 사진으로 찍은 것처럼 보여야 해.

[재질·질감 – 가장 중요]
- 표면 전체에 코바늘 뜨개 코(스티치) 무늬가 또렷하게 보임. 굵은 실로 떠서 코가 큼직함 (작게 줄여도 무늬가 보이게)
- 솜을 넣어 통통하고 부드럽게 부푼 형태, 모서리는 전부 둥글게
- 눈은 작고 반짝이는 검은 단추(안전눈), 코는 주황 실로 수놓음, 입과 앞머리 "ಲ"는 검은 실로 수놓은 자수
- 볼은 분홍 실을 동그랗게 수놓거나 펠트 조각을 붙인 느낌
- 후드와 몸은 민트그린 실, 얼굴은 흰 실로 뜬 둥근 판을 후드 안에 붙인 느낌
- 빨간 스카프는 조금 두툼한 뜨개 목도리처럼, 망토는 얇게 뜬 뜨개 천으로 가장자리에 뜨개 테두리
- 머리 위 이삭은 노란 실로 뜬 작은 알갱이들을 철사 심에 꿰어 세운 느낌
- 실의 보풀이 아주 살짝 보임. 광택 없음

[색상 – 기본 모드와 동일]
- 후드 민트그린, 얼굴 흰색, 이삭 노란색, 망토·스카프 산호빛 빨강, 코 주황, 볼 연한 분홍
- 검은 타원형 눈과 이마의 "ಲ" 앞머리는 원본 그대로

[조명 – 기본 모드와 동일]
- 은은하고 균일한 스튜디오 조명(중립 백색). 색 있는 조명 금지. 뜨개 코가 보일 만큼만 부드러운 음영

[구도 – 반드시 지켜줘]
- 정면에서 본 전신, 머리 위 이삭 끝부터 발끝까지 잘리지 않게
- 캐릭터를 화면 중앙에, 상하좌우로 넉넉한 여백(각 15% 이상)
- 배경은 완전한 순백색 단색(#FFFFFF), 바닥 그림자 없음, 배경 소품 없음
- 이삭이 한 명만, 정사각형(1:1) 비율
```

> 코 무늬가 안 보이면: `뜨개 코가 너무 작아. 굵은 실로 뜬 것처럼 코를 크게` 를 맨 앞에.
> 너무 털북숭이면: `보풀은 거의 없이, 단정하게 뜬 완성품 인형` 으로 조절.

### 1-B단계: 비율 교정 (1차 결과의 형태가 달라졌을 때)

1차(2026-10-21) 결과: 질감은 좋았으나 형태가 "보통 아미구루미 인형" 비율로 바뀜 — 머리가 작고 좁아짐(전체의 60% → 50%), 얼굴이 세로로 길어짐, 몸이 길어져 다리가 보임, 스카프가 리본으로.
가로/세로 비율이 기본 0.64 → 뜨개 0.85. **재질은 1차 결과에서, 형태는 기본 마스터에서** 가져오라고 분리해서 지시.
첨부: `1차 뜨개 결과` + `기본 마스터(idle.png)`

```
첫 번째 이미지는 우리 캐릭터 "이삭이"의 뜨개 인형 시안이고, 두 번째 이미지는 이삭이의 원래 3D 버전이야.
첫 번째 이미지의 "재질"(코바늘 뜨개 질감, 단추 눈, 자수 입, 솜 넣은 느낌)은 그대로 두고,
"형태와 비율"은 두 번째 이미지와 똑같이 고쳐줘. 지금 시안은 보통 인형 비율이라 이삭이 같지 않아.

[형태 – 두 번째 이미지 기준으로 반드시]
- 머리(후드)가 전체 높이의 약 60%를 차지하는 큰 머리. 몸은 짧고 작음
- 머리 폭이 몸 폭의 1.5배 이상. 후드는 위가 뾰족한 물방울 모양으로 옆으로 넓게 퍼짐
- 얼굴은 세로가 아니라 가로로 넓은 타원(폭이 높이보다 큼)으로, 후드 아래쪽을 넓게 차지함
- 눈은 얼굴 가운데 높이에, 볼은 얼굴 양쪽 끝 아래에 크게. 입은 작게
- 몸통은 통통하고 짧으며 다리는 거의 안 보이고 흰 발만 살짝 보임
- 망토는 몸통 뒤에서 거의 바닥까지 내려옴. 스카프는 리본이 아니라 목에 두른 작은 삼각 스카프(매듭은 작게)
- 전체 실루엣의 가로:세로 비율은 약 2:3 (옆으로 넓은 느낌)

[재질 – 첫 번째 이미지 그대로]
- 큼직한 코바늘 뜨개 코, 솜 넣어 통통함, 검은 단추 눈, 주황 실 코, 검은 실 자수 입·앞머리, 분홍 실 볼

[색상·조명·구도는 1단계와 동일]
```

> 머리가 여전히 작으면: `머리를 더 크게. 머리 하나가 몸 전체보다 커야 해` 를 맨 앞에.

### 2단계: 동작별 공통 프롬프트

첨부: `뜨개 마스터 이미지` + `해당 동작 2D 원본`

```
첫 번째 이미지는 뜨개 인형 스타일 이삭이의 기준 이미지이고, 두 번째 이미지는 2D 원본 동작이야.
두 번째 이미지의 포즈와 표정을, 첫 번째 이미지와 완전히 같은 손뜨개 재질·색상·비율·조명으로 만들어줘.

[동작 설명]
{gemini-image-prompts.md의 동작별 표에서 복사}

[재질]
- 첫 번째 이미지와 동일한 코바늘 뜨개 질감 (큼직한 코 무늬, 솜 넣은 통통한 형태, 자수로 된 눈·코·입)
- 움직이는 부분(팔·망토·다리)도 뜨개 코가 이어져 보이게, 구부러진 곳은 코가 살짝 늘어난 느낌

[구도 – 반드시 지켜줘]
- 캐릭터 크기와 머리 비율은 기준 이미지와 동일하게
- 머리 위 이삭 끝부터 발끝(망토 끝)까지 잘리지 않게, 화면 중앙에 넉넉한 여백
- 배경은 완전한 순백색 단색(#FFFFFF), 바닥 그림자 없음, 배경 소품 없음
- 캐릭터 몸 밖에 떠 있는 효과 기호(소리선, 느낌표, 낙서 등)는 그리지 마
- 작은 새싹 캐릭터가 있다면 빼고 이삭이 한 명만
- 정사각형(1:1) 비율
```

### 테스트 순서 (최소 세트)

1. `idle` (00_기본) ← 마스터. **220px로 줄여서** 기본 모드와 나란히 비교
2. `blink` (마스터에서 눈만 감기)
3. `runA` (02_뛰어)
4. `alarm` (10_알림)

### 앱에 넣을 때 (개발 메모)

- 이미지 로더가 `img/` 아래 고정 경로를 읽으므로, `img/winter/`를 두고 `state.style`에 따라 경로 접두어만 바꿈. 파일 이름 세트는 동일.
- 트레이 "🎨 캐릭터 스타일": 자동(계절) / 기본 / 겨울. 자동이면 12~2월에 겨울 세트.
- 겨울 세트에 빠진 포즈는 기본 모드 이미지로 대체(폴백).
- 게임 스프라이트는 별도라 1차에서는 펫만.
- 나중에 다른 계절(봄 꽃, 여름 밀짚모자 등)도 같은 구조로 추가 가능.

## (기록) 점토 인형 모드 — 접음

2026-10-21 두 번 시도. 1차는 "매끈한 무광 3D", 2차(지문·비대칭·이음새를 열거한 강조 버전)도 거의 같은 결과.
원인: 기본 3D 자체가 이미 "무광 클레이 피규어" 질감으로 만들어져 있어서 출발점이 같음. 작은 크기에서는 더욱 차이가 없음.
프롬프트는 아래에 남겨 둠 (다른 캐릭터에 쓸 일이 있을 수 있음).

### 점토 1단계 마스터 프롬프트 (기록)

참고 이미지: 동료가 보내 준 점토 인형 노부부 그림. 핵심은 **손으로 빚은 폴리머 클레이 느낌**입니다.
기본 모드(매끈한 비닐 피규어)와 달리 표면에 아주 미세한 지문·도구 자국이 있고, 모서리가 두툼하고 둥급니다.
조명은 기본 모드와 똑같이 중립 스튜디오 조명으로 둡니다. 참고 이미지의 따뜻한 느낌은 거실 배경에서 오는 것이라, 캐릭터에 넣으면 색이 변하고 배경 제거가 어려워집니다.

### 1단계: 마스터 프롬프트

첨부: `점토 인형 참고 이미지(노부부)` + `기본 모드 마스터(idle.png)` + `00_기본.png`

```
첫 번째 이미지는 우리가 원하는 "점토 인형" 스타일의 참고 이미지이고,
두 번째 이미지는 우리 기관 캐릭터 "이삭이"의 현재 3D 버전,
세 번째 이미지는 이삭이의 2D 원본 디자인(기본 포즈)이야.

이삭이를 첫 번째 이미지와 똑같은 "손으로 빚은 점토 인형" 스타일로 다시 만들어줘.
캐릭터의 생김새·색·비율은 두 번째 이미지를 그대로 따르고, 재질과 질감만 바꿔줘.

[재질·질감 – 가장 중요]
- 폴리머 클레이(플라스티신)로 손으로 빚은 인형. 표면은 무광이고 아주 살짝 울퉁불퉁하며, 가까이 보면 미세한 지문·도구 자국이 보임
- 모든 모서리와 끝이 두툼하고 둥글게 뭉툭함 (날카로운 선 없음)
- 눈은 검은 점토를 작게 붙인 느낌, 볼은 연한 분홍 점토를 살짝 문질러 바른 느낌
- 후드·망토·스카프는 점토 판을 얇게 밀어 덮은 느낌으로 가장자리가 조금 두꺼움
- 머리 위 이삭(벼)은 노란 점토 알갱이를 하나씩 붙인 것처럼
- 스톱모션 애니메이션(아드만 스튜디오 느낌)의 실물 인형처럼, 실제 사진같은 질감

[색상 – 기본 모드와 동일]
- 후드 민트그린, 얼굴 흰색(살짝 크림빛), 이삭 노란색, 망토·스카프 산호빛 빨강, 코 작은 주황, 볼 연한 분홍
- 이마의 꼬불한 "ಲ" 모양 앞머리, 검은 타원형 눈은 원본 그대로

[조명 – 기본 모드와 동일]
- 은은하고 균일한 스튜디오 조명(중립 백색). 햇살·노을 같은 색 있는 조명은 쓰지 마
- 참고 이미지의 따뜻한 분위기는 배경에서 오는 것이니 따라 하지 말고, 캐릭터 색이 원래 색 그대로 보이게

[구도 – 반드시 지켜줘]
- 정면에서 본 전신, 머리 위 이삭 끝부터 발끝까지 잘리지 않게
- 캐릭터를 화면 중앙에, 상하좌우로 넉넉한 여백(각 15% 이상)
- 배경은 완전한 순백색 단색(#FFFFFF), 바닥 그림자 없음, 배경 소품 없음
- 참고 이미지의 인물·소파·거실은 절대 그리지 마. 이삭이 한 명만
- 정사각형(1:1) 비율
```

### 1-B단계: 강조 버전 (1차 결과가 기본 모드와 비슷할 때)

1차 테스트(2026-10-21) 결과가 "매끈한 무광 3D"로 나와 기존과 구분이 안 됐음. "점토"라는 단어만으로는 부족하고 **손으로 만든 흔적을 하나씩 열거**해야 함.
첨부: `1차 점토 결과 이미지` + `2D 원본 00_기본.png`

```
첫 번째 이미지는 우리 캐릭터 "이삭이"를 점토 인형으로 만든 1차 시안인데, 너무 매끈해서
컴퓨터 3D 렌더링처럼 보여. 같은 생김새·색·포즈를 유지하면서, 누가 봐도 "손으로 빚은 진짜 점토 인형을
접사 촬영한 사진"으로 보이게 다시 만들어줘. 두 번째 이미지는 2D 원본 디자인이야.

[반드시 눈에 보여야 하는 것]
- 표면 전체에 지문 자국과 손가락으로 문지른 결이 또렷하게 보임 (특히 후드·몸통·망토의 넓은 면)
- 표면이 살짝 울퉁불퉁하고 매끈하지 않음. 완벽한 구·곡면이 아니라 손으로 굴린 듯 조금 찌그러진 형태
- 좌우가 완벽히 대칭이 아님. 눈 크기·볼 위치·앞머리 곡선이 아주 살짝 어긋남
- 점토 조각을 붙인 이음새가 보임: 얼굴과 후드 경계, 팔이 몸에 붙는 자리, 스카프·망토가 몸에 붙는 자리에 눌러 붙인 자국
- 눈·코·입·앞머리는 가는 점토 끈을 올려 붙인 것처럼 살짝 도톰하게 튀어나옴 (그려 넣은 선이 아님)
- 머리 위 이삭은 노란 점토 알갱이를 하나씩 손으로 눌러 붙인 느낌, 크기가 조금씩 다름
- 망토와 스카프는 점토를 얇게 밀어 편 판이라 두께가 고르지 않고 가장자리가 울퉁불퉁함
- 모서리와 끝부분은 전부 두툼하고 뭉툭함. 날카로운 선이나 얇은 부분 없음
- 무광에 아주 살짝 먼지 낀 듯한 질감. 광택·반사·하이라이트 없음
- 색은 점토 고유색이라 살짝 덜 채도 높고, 같은 색 안에서도 미세하게 얼룩덜룩함

[스타일 참고]
- 스톱모션 클레이 애니메이션(아드만 스튜디오 '월레스와 그로밋', '숀 더 쉽')의 실물 인형
- 매크로 렌즈로 가까이 찍은 사진. 디지털 3D 렌더링이 아님

[색상 – 기본 모드와 동일]
- 후드 민트그린, 얼굴 흰색(살짝 크림빛), 이삭 노란색, 망토·스카프 산호빛 빨강, 코 작은 주황, 볼 연한 분홍
- 이마의 꼬불한 "ಲ" 모양 앞머리, 검은 타원형 눈은 원본 그대로

[조명 – 기본 모드와 동일]
- 은은하고 균일한 스튜디오 조명(중립 백색). 색 있는 조명 금지. 질감이 보일 만큼만 아주 부드러운 음영

[구도 – 반드시 지켜줘]
- 정면 전신, 머리 위 이삭 끝부터 발끝까지 잘리지 않게, 화면 중앙에 넉넉한 여백(각 15% 이상)
- 배경은 완전한 순백색 단색(#FFFFFF), 바닥 그림자 없음, 배경 소품 없음
- 이삭이 한 명만, 정사각형(1:1)
```

> 이래도 매끈하면 맨 앞에 `지문 자국이 너무 안 보여. 손자국이 과하다 싶을 만큼 또렷하게` 를 붙여 한 번 더.
> 반대로 너무 거칠거나 지저분하면 `지문 자국은 은은하게, 형태는 단정하게, 완성품 인형처럼` 으로 조절.
> 참고: 노부부 참고 이미지 자체가 꽤 매끈한 편이라, 그 이미지를 첨부하면 오히려 매끈한 쪽으로 끌려감. 강조 버전에서는 빼는 게 나음.
