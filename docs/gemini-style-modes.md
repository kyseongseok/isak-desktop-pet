# 이삭이 스타일 모드 이미지 제작 가이드 (Gemini용)

동료 요청: "점토 인형처럼", "뜨개(패브릭) 인형처럼" 해 달라.
→ 스타일을 여러 벌 만들어 두고 **트레이 메뉴에서 모드를 고르는** 방식으로 가기로 함.

| 모드 | 폴더(예정) | 상태 |
|---|---|---|
| 기본 (무광 비닐 피규어) | `app/renderer/img/` | 완료 |
| 점토 인형 (클레이) | `app/renderer/img/clay/` | 테스트 중 — 아래 프롬프트 |
| 뜨개 인형 (패브릭) | `app/renderer/img/knit/` | 초안만 |

작업 순서는 [gemini-image-prompts.md](gemini-image-prompts.md)와 같습니다.
**마스터 1장을 먼저 확정**하고, 동작별 이미지는 매번 [마스터] + [2D 원본] 2장을 첨부해 만듭니다.
펫에 들어가려면 포즈 세트가 기본 모드와 **파일 이름이 같아야** 합니다(idle, blink, runA/runB, alarm, fly, surprise, think, best, hello, cheer, curious, research, farm, angry, sleep…).

---

## 점토 인형(클레이) 모드

참고 이미지: 동료가 보내 준 점토 인형 노부부 그림. 핵심은 **손으로 빚은 폴리머 클레이 느낌**입니다.
기본 모드(매끈한 비닐 피규어)와 달리 표면에 아주 미세한 지문·도구 자국이 있고, 모서리가 두툼하고 둥급니다.
조명은 기본 모드와 똑같이 중립 스튜디오 조명으로 둡니다. 참고 이미지의 따뜻한 느낌은 거실 배경에서 오는 것이라, 캐릭터에 넣으면 색이 변하고 배경 제거가 어려워집니다.

### 1단계: 마스터 프롬프트

첨부: `점토 인형 참고 이미지(노부부)` + `기본 모드 마스터(idle.png)` + `00_기본.png`

```
첫 번째 이미지는 우리가 원하는 "점토 인형" 스타일의 참고 이미지이고,
두 번째 이미지는 우리 기관 캐릭터 "이삭이"의 현재 3D 버전,
세 번째 이미지는 이삭이의 2D 원본 디자인(기본 포즈)이야.

이삭이를 첫 번째 이미지와 똑같은 "손으로 빚은 점토 인형" 스타일로 다시 만들어줘.
캐릭터의 생김새·색·비율은 두 번째 이미지를 그대로 따르고, 재질과 질감만 바꿔줘.

[재질·질감 – 가장 중요]
- 폴리머 클레이(플라스티신)로 손으로 빚은 인형. 표면은 무광이고 아주 살짝 울퉁불퉁하며, 가까이 보면 미세한 지문·도구 자국이 보임
- 모든 모서리와 끝이 두툼하고 둥글게 뭉툭함 (날카로운 선 없음)
- 눈은 검은 점토를 작게 붙인 느낌, 볼은 연한 분홍 점토를 살짝 문질러 바른 느낌
- 후드·망토·스카프는 점토 판을 얇게 밀어 덮은 느낌으로 가장자리가 조금 두꺼움
- 머리 위 이삭(벼)은 노란 점토 알갱이를 하나씩 붙인 것처럼
- 스톱모션 애니메이션(아드만 스튜디오 느낌)의 실물 인형처럼, 실제 사진같은 질감

[색상 – 기본 모드와 동일]
- 후드 민트그린, 얼굴 흰색(살짝 크림빛), 이삭 노란색, 망토·스카프 산호빛 빨강, 코 작은 주황, 볼 연한 분홍
- 이마의 꼬불한 "ಲ" 모양 앞머리, 검은 타원형 눈은 원본 그대로

[조명 – 기본 모드와 동일]
- 은은하고 균일한 스튜디오 조명(중립 백색). 햇살·노을 같은 색 있는 조명은 쓰지 마
- 참고 이미지의 따뜻한 분위기는 배경에서 오는 것이니 따라 하지 말고, 캐릭터 색이 원래 색 그대로 보이게

[구도 – 반드시 지켜줘]
- 정면에서 본 전신, 머리 위 이삭 끝부터 발끝까지 잘리지 않게
- 캐릭터를 화면 중앙에, 상하좌우로 넉넉한 여백(각 15% 이상)
- 배경은 완전한 순백색 단색(#FFFFFF), 바닥 그림자 없음, 배경 소품 없음
- 참고 이미지의 인물·소파·거실은 절대 그리지 마. 이삭이 한 명만
- 정사각형(1:1) 비율
```

> 결과가 "그냥 매끈한 3D"로 나오면: 프롬프트 맨 앞에 `사진처럼 찍은 실제 점토 인형, 표면에 지문 자국이 보이게` 를 한 줄 더 넣어 보세요.
> 너무 거칠게 나오면: `지문 자국은 아주 은은하게, 전체적으로는 깔끔한 완성품 인형` 으로 조절.

### 2단계: 동작별 공통 프롬프트

첨부: `점토 마스터 이미지` + `해당 동작 2D 원본`

```
첫 번째 이미지는 점토 인형 스타일 이삭이의 기준 이미지이고, 두 번째 이미지는 2D 원본 동작이야.
두 번째 이미지의 포즈와 표정을, 첫 번째 이미지와 완전히 같은 점토 인형 재질·색상·비율·조명으로 만들어줘.

[동작 설명]
{gemini-image-prompts.md의 동작별 표에서 복사}

[재질]
- 첫 번째 이미지와 동일한 손으로 빚은 폴리머 클레이 질감 (무광, 미세한 지문 자국, 둥글고 두툼한 모서리)
- 움직이는 부분(팔·망토·다리)도 점토가 구부러진 것처럼 두툼하게

[구도 – 반드시 지켜줘]
- 캐릭터 크기와 머리 비율은 기준 이미지와 동일하게
- 머리 위 이삭 끝부터 발끝(망토 끝)까지 잘리지 않게, 화면 중앙에 넉넉한 여백
- 배경은 완전한 순백색 단색(#FFFFFF), 바닥 그림자 없음, 배경 소품 없음
- 캐릭터 몸 밖에 떠 있는 효과 기호(소리선, 느낌표, 낙서, 손 흔드는 선 등)는 그리지 마
- 작은 새싹 캐릭터가 있다면 빼고 이삭이 한 명만
- 정사각형(1:1) 비율
```

### 테스트 순서 (최소 세트)

점토 모드가 펫에서 어떻게 보이는지만 보려면 아래 4장이면 됩니다.

1. `idle` (00_기본) ← 마스터
2. `blink` (마스터에서 눈만 감기: "눈을 감은 버전, 나머지는 완전히 동일하게")
3. `runA` (02_뛰어) — 걷기
4. `alarm` (10_알림) — 근무확인 알람

배경 제거는 기존과 같이 `tools/remove-bg.swift`로 처리합니다. 점토 질감은 외곽이 살짝 거칠어서 흰 테두리가 남으면 임계값을 조금 올려 보세요.

## 뜨개 인형(패브릭) 모드 — 초안

마스터 프롬프트의 [재질·질감] 블록만 아래로 바꿔 쓰면 됩니다. 나머지(색상·구도)는 동일.

```
[재질·질감 – 가장 중요]
- 털실로 코바늘 뜨기한 아미구루미 인형. 표면 전체에 촘촘한 뜨개 코(스티치) 무늬가 보임
- 솜을 넣어 통통하고 부드럽게 부푼 형태, 모서리는 모두 둥글게
- 눈은 검은 단추 또는 자수, 볼은 분홍 실로 수놓거나 살짝 블러셔
- 망토·스카프는 얇게 뜬 뜨개 천이 덮인 느낌, 가장자리에 뜨개 테두리
- 머리 위 이삭은 노란 실로 뜬 작은 알갱이들
- 실제 손뜨개 인형을 사진으로 찍은 것 같은 질감, 실의 보풀이 아주 살짝 보임
```

> 뜨개 코 무늬는 작은 크기(펫 기본 220px)로 줄이면 뭉개져 보일 수 있어요. 코를 조금 크게 뜬 느낌(굵은 실)으로 요청하는 게 펫에서 더 잘 읽힙니다.

## 앱에 넣을 때 (개발 메모)

- 이미지 로더가 `img/` 아래 고정 경로를 읽으므로, 모드별 하위 폴더(`img/clay/`, `img/knit/`)를 두고 `state.style`에 따라 경로 접두어만 바꾸면 됨. 파일 이름 세트는 동일해야 함.
- 트레이 메뉴 "🎨 캐릭터 스타일" 서브메뉴(기본 / 점토 인형 / 뜨개 인형) → 저장 후 즉시 교체(재시작 불필요).
- 모드별로 포즈가 빠져 있으면 기본 모드 이미지로 대체(폴백)해서 깨지지 않게.
- 게임(과수원·타자)의 이삭이 스프라이트는 별도 파일이라 1차에서는 펫만 적용.
