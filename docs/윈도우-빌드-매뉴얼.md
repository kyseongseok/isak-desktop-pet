# 이삭이 데스크톱 펫 — 윈도우 설치 파일 만들기

외부망 윈도우 PC에서 소스 압축파일로 설치본(`이삭이-설치-x.y.z.exe`)을 만드는 절차입니다.
인터넷이 되는 PC에서 해야 해요 (npm 패키지와 Electron 바이너리를 내려받습니다).

## 0. 준비물

| 항목 | 내용 |
|---|---|
| Node.js | **LTS 22.x** (https://nodejs.org → LTS 다운로드 → 기본값으로 설치). 설치 후 새 터미널에서 `node -v`, `npm -v` 확인 |
| 소스 | `이삭이-소스-v0.1.0.zip` → 한글·공백 없는 경로에 풀기 (예: `C:\work\isak-pet`) |
| 디스크 | 1 GB 정도 여유 (Electron 바이너리 + 빌드 캐시) |

> 경로에 한글이나 공백이 있으면 electron-builder가 가끔 실패해요. `C:\work\isak-pet`처럼 짧고 영문인 경로를 권장합니다.

## 1. 의존성 설치

PowerShell 또는 명령 프롬프트를 열고 소스 폴더로 이동한 뒤:

```
cd C:\work\isak-pet
npm install
```

- 2~5분 걸려요. 끝나면 `node_modules\electron\dist\electron.exe`가 있어야 합니다.
- **만약** `Electron failed to install correctly` 가 뜨면 (npm 11 이상에서 설치 스크립트가 막히는 경우):
  ```
  node node_modules\electron\install.js
  ```

## 2. 실행해서 한 번 확인 (선택이지만 추천)

```
npm start
```

- 이삭이가 바탕화면에 뜨고, 작업표시줄 오른쪽 알림 영역에 트레이 아이콘이 생기면 정상.
- 우클릭 메뉴, 미니게임, 알람 소리 테스트(트레이 → 알람 소리 → 지금 테스트)를 눌러 봅니다.
- 끝났으면 우클릭 → 종료.

## 3. 설치 파일 만들기

```
npm run build:win
```

- 처음 한 번은 NSIS·winCodeSign 같은 도구를 내려받아서 5~10분 걸려요.
- 완성되면 `dist\이삭이-설치-0.1.0.exe` 가 생깁니다. **이 파일 하나만** 동료에게 주면 돼요.
- 설치본은 **사용자 단위 설치**라 관리자 권한이 필요 없고, 설치 후 바로 실행되며 바탕화면·시작 메뉴 바로가기가 생깁니다.

### 자주 나는 오류

| 증상 | 해결 |
|---|---|
| `Cannot create symbolic link` / `A required privilege is not held` | 윈도우 **개발자 모드**를 켜거나(설정 → 개인 정보 및 보안 → 개발자용 → 개발자 모드), PowerShell을 **관리자 권한으로** 열어서 다시 `npm run build:win` |
| `ETIMEDOUT`, `ECONNRESET` 등 다운로드 실패 | 회사 프록시 때문일 수 있어요. 인터넷이 바로 되는 PC에서 하거나, `npm config set proxy http://주소:포트` 설정 |
| `rcedit` / 아이콘 관련 오류 | `app\renderer\img\idle.png`가 있는지 확인. 없으면 압축을 다시 풀기 |
| 빌드는 됐는데 실행 시 흰 화면 | `app\game\words\` 폴더와 `app\game\img\`가 함께 들어갔는지 확인 (압축 풀 때 폴더 구조가 유지돼야 함) |

## 4. 설치본 확인

1. `dist\이삭이-설치-0.1.0.exe` 더블클릭 → 설치 → 자동 실행
2. 처음 실행이면 튜토리얼이 뜹니다 (10단계, 건너뛰기 가능)
3. 확인할 것:
   - 우클릭 메뉴가 뜨는지, 이모지가 깨지지 않는지
   - 트레이 아이콘(작업표시줄 오른쪽, 숨겨진 아이콘은 `^` 안)과 그 메뉴
   - 트레이 → 알람 소리 → **알람 흐름 테스트**: 5·3·1분 전·초과가 15초 간격으로 울리고 화면이 깜빡이는지
   - 윈도우 알림센터에 토스트가 뜨는지 (집중 모드가 켜져 있으면 안 뜸)
   - 미니게임 2종 (코인은 처음 5개). **타자게임에서 한글 입력이 정상인지** 꼭 확인
   - 재부팅 후 자동 실행되는지 (트레이 → 부팅 시 자동 실행 체크 상태)
4. 설정·기록 파일 위치: `%APPDATA%\이삭이\state.json` (문제가 생기면 이 파일을 지우고 다시 실행하면 초기화)
5. 제거: 설정 → 앱 → 이삭이 → 제거

## 5. 버전 올리기

`package.json`의 `"version": "0.1.0"`을 바꾸고 다시 `npm run build:win` 하면 파일 이름에 새 버전이 붙습니다.

## 6. 배포 시 알아둘 것

- 설치본은 코드 서명이 없어서 처음 실행할 때 **SmartScreen 경고**("Windows의 PC 보호")가 뜰 수 있어요. "추가 정보 → 실행"으로 넘어가면 됩니다. 동료들에게 미리 알려 주세요.
- 배경음악 출처·라이선스는 `app\game\music\CREDITS.txt`에 적어 두세요.
- 공휴일 목록은 `app\holidays.js`에 2026·2027년이 들어 있어요. 해마다 갱신이 필요합니다.
