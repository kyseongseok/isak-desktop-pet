# 이삭이 3D 이미지 제작 가이드 (Gemini용)

## 준비물

- **2D 원본 PNG**: `assets/source-2d/png/` (ai 파일을 PNG로 변환해 둠, 13종)
- **3D 스타일 기준 이미지**: 이미 만들어 둔 3D 이삭이 (돋보기 들고 있는 이미지 추천)

## 작업 순서

1. **1단계 – 기준(마스터) 이미지 만들기**: `00_기본` 포즈를 3D로 만들고, 마음에 들 때까지 다시 생성합니다. 이 결과물이 이후 모든 이미지의 기준이 됩니다.
2. **2단계 – 동작별 이미지**: 매번 **[마스터 3D 이미지] + [해당 동작 2D 원본]** 2장을 첨부하고 아래 프롬프트를 사용합니다.
3. **3단계 – 변형 이미지**: 깜빡임용 등 마스터를 살짝 수정한 버전을 만듭니다.

> 💡 같은 대화창에서 이어서 만들면 스타일이 더 잘 유지됩니다. 결과가 흔들리기 시작하면 새 대화에서 마스터 이미지를 다시 첨부하세요.

## 1단계: 마스터 이미지 프롬프트

첨부: `3D 스타일 기준 이미지` + `00_기본.png`

```
첫 번째 이미지는 우리 기관 캐릭터 "이삭이"의 3D 스타일 참고 이미지이고,
두 번째 이미지는 이삭이의 2D 원본 디자인(기본 포즈)이야.

두 번째 이미지의 포즈와 표정을, 첫 번째 이미지와 똑같은 3D 스타일로 만들어줘.

[스타일]
- 부드러운 무광 비닐/클레이 피규어 질감의 3D 렌더링, 은은한 스튜디오 조명
- 2D 원본의 검은 외곽선은 없애고 입체감으로 표현
- 색상: 후드는 민트그린, 얼굴은 흰색, 머리 위 이삭은 노란색, 망토와 목 스카프는 산호빛 빨강, 코는 작은 주황색, 볼은 연한 분홍
- 이마의 꼬불한 "ಲ" 모양 앞머리, 검은 타원형 눈은 원본 그대로 유지

[구도 – 반드시 지켜줘]
- 정면에서 본 전신, 머리 위 이삭 끝부터 발끝까지 잘리지 않게
- 캐릭터를 화면 중앙에, 상하좌우로 넉넉한 여백(각 15% 이상)
- 배경은 완전한 순백색 단색(#FFFFFF), 바닥 그림자 없음, 배경 소품 없음
- 원본 오른쪽에 있는 작은 새싹 캐릭터는 빼고 이삭이 한 명만
- 정사각형(1:1) 비율
```

두 번째 이미지의 포즈와 표정을, 첫 번째 이미지와 완전히 같은 3D 스타일·색상·질감·비율로 만들어줘.

## 3단계: 변형 이미지 (마스터 이미지를 수정)

첨부: `마스터 3D 이미지` 1장만

**① 눈 깜빡임용** (대기 중 깜빡임 애니메이션)
```
이 이미지에서 다른 건 전혀 바꾸지 말고, 눈만 편안하게 감은 상태(아래로 휜 곡선 눈)로 바꿔줘.
포즈, 크기, 위치, 색상, 배경은 픽셀 단위로 동일하게 유지해줘.
```

**② 졸음** (늦은 밤에 오래 방치됐을 때)
```
이 이미지와 같은 스타일로, 이삭이가 서서 꾸벅꾸벅 조는 모습으로 바꿔줘.
눈을 감고, 고개를 살짝 한쪽으로 기울이고, 입은 작게 벌린 모습.
크기·비율·배경(순백색, 그림자 없음)은 그대로 유지해줘.
```

- 배경 제거, Gemini 워터마크(오른쪽 아래 ✦) 정리, 크기 맞추기는 개발 단계에서 처리합니다.

## 결과물 체크리스트

- [ ] 머리 위 이삭 끝, 발끝, 망토 끝이 잘리지 않았다
- [ ] 바닥 그림자가 없다 (그림자는 점프할 때 따로 그립니다)
- [ ] 후드 색이 마스터와 같은 민트그린이다 (연해지거나 진해지지 않았다)
- [ ] 코가 주황색이다 (분홍으로 바뀌는 경우가 있음)
- [ ] 캐릭터 몸 밖에 효과 기호가 없다
- [ ] 워터마크 ✦가 캐릭터와 겹치지 않았다
