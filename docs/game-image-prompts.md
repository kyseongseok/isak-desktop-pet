# 과수원을 지켜라 — 그래픽 방향과 이미지 제작 가이드

## 1. 아트 방향: "클레이 디오라마 + 픽셀 UI" (추천)

| 방향 | 장점 | 단점 |
|---|---|---|
| A. 전부 레트로 픽셀 | 게임 느낌이 확실, 인트로가 예쁨, 이미지가 가벼움 | 이삭이를 픽셀로 다시 그려야 함(2벌 관리), AI 픽셀아트는 격자가 안 맞는 경우가 많음 |
| B. 전부 3D 클레이 (펫과 동일) | 펫과 완전히 같은 세계, 이삭이 포즈 재활용 | "게임"보다 "광고"처럼 보일 수 있음, 이미지가 무거움 |
| **C. 혼합 (추천)** | 캐릭터·과일·아이템은 **클레이 3D**, 제목·점수판·버튼은 **픽셀 폰트와 픽셀 프레임** | 두 스타일이 섞여서 어색하지 않게 UI를 절제해야 함 |

C는 "장난감 디오라마를 레트로 게임기로 찍은 느낌"이에요. 이삭이가 그대로 등장하면서도 인트로·HUD에서 레트로 감성이 나요. 나중에 원하면 "레트로 모드"(전부 픽셀)를 옵션으로 추가할 수도 있어요.

### 픽셀 폰트
- **Galmuri** (갈무리, OFL 무료): 한글 픽셀 폰트, 게임 제목·점수·버튼에 사용. https://github.com/quiple/galmuri
- 폰트 파일은 앱에 같이 넣으니 별도 작업 없음

## 2. 게임 창 크기

- 논리 크기 **480 × 800** (세로형, 9:15). 1080p 모니터에서 작업표시줄을 빼도 들어가는 높이
- 배경 이미지는 **9:16 (1024 × 1792 또는 1080 × 1920)**로 만들고 위아래를 살짝 잘라 씀
- 고해상도 모니터 대비 배경은 1080 × 1920, 아이콘은 256 × 256 이상

## 3. 화면 구성 (이미지가 어디에 쓰이는지)

```
┌────────────────────┐
│ 하늘·구름·새 (배경 위쪽)  │  ← 새가 좌우로 날며 똥을 떨어뜨림
│                    │
│   🍎  💩   🧊        │  ← 떨어지는 과일·위험물·아이템
│                    │
│ 사과나무 (양옆)        │  ← 배경의 일부
│  ┌─이삭이(바구니)─┐    │  ← 바닥에서 좌우 이동
│ 풀밭 (바닥 띠)        │
└────────────────────┘
 ♥♥♥♥♥  점수 1,240  STAGE 3   ← HUD는 코드(픽셀 폰트)로
```

## 4. 필요한 이미지 목록

| # | 항목 | 수량 | 용도 | 제작 |
|---|---|---|---|---|
| 1 | 과수원 배경 (하늘+나무+풀밭) | 1 | 게임 바탕 | Gemini |
| 2 | 인트로 배경 | 1 | 시작 화면 (배경 1을 재활용해도 됨) | Gemini 또는 재활용 |
| 3 | 과일 | 3 (사과·배·감) | 받으면 점수 | Gemini (한 장에 격자) |
| 4 | 위험물 | 4 (새똥·우박·벌레·부러진 가지) | 맞으면 하트 -1 | Gemini (한 장에 격자) |
| 5 | 아이템 | 6 (번개·우산·황금 이삭·자석·새싹이·거북이) | 효과 | Gemini (한 장에 격자) |
| 6 | 새 | 1~2 | 하늘에서 날아다님 | Gemini |
| 7 | 이삭이 우산 포즈 | 1 | 쉴드 중 | Gemini (기존 가이드 방식) |
| 8 | 하트·점수판·버튼·스테이지 배너 | — | HUD | **코드로 그림** (픽셀 폰트) |

이삭이의 다른 상태는 이미 있는 이미지를 써요: 기본 이동 = `04_농산물`(바구니), 맞음 = `12_놀람`, 게임 오버 = `00_기본_졸음B`, 클리어 = `05_축하&응원`, 번개 = `02_뛰어`.

## 5. 프롬프트

모든 프롬프트는 **3D 이삭이 마스터 이미지(`00_기본.png`)를 함께 첨부**해서 질감을 맞춰요.

### 5-1. 과수원 배경

```
첨부한 캐릭터 이미지와 같은 부드러운 무광 클레이/비닐 피규어 질감의 3D 렌더링으로,
모바일 세로 게임의 배경을 만들어줘.

[장면]
- 한국의 사과 과수원. 맑은 하늘에 뭉게구름 몇 개, 멀리 낮은 언덕
- 화면 양옆에 사과나무가 한 그루씩, 가지가 화면 위쪽으로 뻗어 있음 (가운데는 비워둠)
- 바닥은 짧은 풀밭. 화면 아래 15%는 평평한 풀밭으로 캐릭터가 서 있을 자리
- 따뜻한 오후 햇빛, 밝고 귀여운 분위기, 채도는 캐릭터의 민트·노랑과 어울리게 파스텔

[구도 – 반드시 지켜줘]
- 세로 9:16 비율
- 화면 가운데 세로 영역(폭의 60%)은 나무·구름 같은 큰 물체가 없게 비워둠 (게임 오브젝트가 떨어지는 자리)
- 캐릭터, 사람, 글자, 로고, UI 없음
- 전체적으로 살짝 흐릿한 배경(피사계 심도)이면 좋음
```

### 5-2. 인트로 화면 배경 (선택)

```
위와 같은 과수원 배경이지만 인트로용으로:
- 화면 위쪽 35%는 하늘만 있어서 제목을 넣을 수 있게 비워둠
- 화면 아래 중앙에 첨부한 이삭이 캐릭터가 바구니를 들고 서서 정면을 보며 웃고 있음
- 캐릭터 주변에 떨어지는 사과 2~3개가 공중에 떠 있음 (움직임 느낌)
- 글자, 로고, 버튼은 넣지 마 (코드로 넣을 거야)
- 세로 9:16 비율
```

### 5-3. 과일 + 위험물 격자 (한 장)

```
첨부한 캐릭터와 같은 클레이 피규어 질감의 3D 아이콘 7개를 한 장에 만들어줘.
순백색 배경(#FFFFFF), 그림자 없음, 정사각형 이미지, 가로 4칸 × 세로 2칸 격자로 같은 크기로 배치.
각 아이콘은 칸 안에 여백을 두고 중앙에, 정면 또는 약간 위에서 본 각도.

1행: 빨간 사과 / 노란 배 / 주황 감(꼭지 있음) / (빈칸)
2행: 새똥(흰색+회색 물방울 모양, 귀엽게) / 우박 덩어리(연한 하늘색 얼음, 울퉁불퉁) / 초록 애벌레(동그란 눈, 귀엽게) / 부러진 나뭇가지(갈색, 잎 두 장)

아이콘끼리 겹치지 않게, 글자나 번호는 넣지 마.
```

### 5-4. 아이템 격자 (한 장)

```
첨부한 캐릭터와 같은 클레이 피규어 질감의 3D 아이템 아이콘 6개를 한 장에 만들어줘.
순백색 배경, 그림자 없음, 정사각형 이미지, 가로 3칸 × 세로 2칸 격자, 같은 크기.
각 아이콘은 동그란 연노랑 코인 모양 받침 위에 올려서 "아이템"처럼 보이게.

1행: 노란 번개 / 빨간 우산(펼친 모습) / 황금색으로 빛나는 벼 이삭(캐릭터 머리 위 이삭과 같은 모양)
2행: 빨간·파란 말굽자석 / 새싹이(첨부한 2D 이미지의 작은 새싹 캐릭터를 3D로, 머리에 초록 잎 두 장, 크림색 몸) / 초록 거북이(귀엽게)

글자나 번호는 넣지 마.
```
> 새싹이는 `assets/source-2d/png/00_기본.png` 오른쪽의 작은 캐릭터를 같이 첨부하세요.

### 5-5. 새

```
첨부한 캐릭터와 같은 클레이 질감의 3D 새 두 마리를 한 장에, 순백색 배경, 그림자 없음.
왼쪽: 날개를 위로 든 모습 / 오른쪽: 날개를 아래로 내린 모습 (같은 새, 날갯짓 2컷)
통통한 파란 참새 느낌, 동그란 눈, 작은 주황 부리, 옆모습(왼쪽을 향함). 글자 없음.
```

### 5-6. 이삭이 우산 포즈

기존 `docs/gemini-image-prompts.md`의 공통 프롬프트에 이 [동작 설명]을 넣으세요:
```
빨간 우산을 머리 위로 펼쳐 들고 서 있는 포즈, 살짝 긴장한 표정(눈은 동그랗게, 입은 작게 "o"),
우산은 머리 전체를 덮을 만큼 크게. 바구니는 없음.
```
결과물은 `assets/source-3d/14_우산.png`로 저장.
